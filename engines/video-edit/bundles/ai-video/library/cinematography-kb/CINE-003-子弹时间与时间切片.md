# 子弹时间与时间切片（Bullet Time / Time Slice）

> 主题编号：CINE-003　版本：v1.0　更新日期：2026-10-30

## 核心概念

子弹时间不是“慢动作”同义词。它的可观察结构是：

```text
主体时间：正常 → 压慢 → 冻结/近冻结 → 恢复
摄影机时间：持续运动，不跟着主体停住
空间证据：摄影机绕行产生真实视差
```

只有主体慢、摄影机也几乎不动，是普通升格；只有静态图推拉，是二维假环绕。

## 可执行层次

| 层次 | 做法 | 可宣称 |
|---|---|---|
| 连续单次 AI 生成 | 25 字段 + 多图参考，90–120° 连续环绕 | 连续 AI 子弹时间镜头 |
| 参考视频引导 | 图片锁主体，白模视频只锁摄影机和时间 | 引导式环绕 |
| 分段视角 | 3–5 个固定视角匹配剪辑 | 分段环绕，不是完全连续 |
| 静帧/2.5D 后期 | 冻结帧 + 景深或视差滑移 | 编辑型伪子弹时间，必须改名 |

## 时间层

默认只锁主体，不锁整个画面：

- 脸、身体和手持道具：locked / near-freeze；
- 发梢、衣摆、袖口：very slow；
- 背景实体：locked；
- 环境粒子：只有剧情动机明确时才启用；
- 摄影机：连续 orbit，零切点。

## 运镜风险

- 60–120°：单主体和多角度参考下最稳。
- 120–180°：需要侧面与背面几何，失败率上升。
- 超过 180°：默认拆段或使用专业重建，不承诺单次生成。
- 边环绕边升降、变焦、切换近景：复合运动风险高，第一版不叠加。

## 提示词映射

要写：

- “一个连续镜头，全程无切点”；
- “人物主体近冻结，摄影机仍缓慢顺时针绕行”；
- “从右前方四分之三视角到左侧面”；
- “入口动作、恢复动作和落点”；
- “真实空间视差，不是二维推拉”；
- “只保留画内脚步、布料和环境声”。

不要写：

- “子弹时间，电影感，8K”；
- 裸 f 值、ISO、快门；
- 360° 单次环绕；
- 镜头外配乐；
- 人物主动旋转替代摄影机运动。

## 失败判据

1. 主体近冻结但摄影机也静止：没形成“时间停、空间继续观察”。
2. 无真实视差：只是静帧缩放。
3. 主体在冻结窗口换脸、换衣、换手或道具跳变：身份合同失败。
4. 有多余切点：连续环绕声明失败。
5. 有摄影机跳位、突然加速或镜头重置：空间路径失败。
6. 生成阶段出现非画内音乐：音频策略失败。
