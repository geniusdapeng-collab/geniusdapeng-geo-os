# 子弹时间镜头工艺

## 适用场景

- 人物做不可逆决定、动作撞击、服装或产品揭示、记忆断裂、主观时间拉长。
- 用户明确说出“子弹时间、时间冻结、时间切片、环绕定格、主体停住但镜头继续动”。
- 单镜需要在 4–30 秒内表现“主体近冻结 + 摄影机继续观察”。

不用于普通慢动作、固定机位定格、单纯推近静帧或只为“看起来酷”的效果堆叠。

## 先判断是否值得

删掉子弹时间后，如果观众只损失“没那么酷”，就不使用。至少满足一项：

1. 看清现实时间中来不及看清的动作或空间关系；
2. 表达人物决定、压力或时间感；
3. 让服装、产品、道具成为故事证据；
4. 建立前后镜无法替代的因果关系；
5. 成为全片唯一、可回收的视觉母题。

## 输出

1. 一个符合 `schemas/bullet-time-effect.schema.json` 的 `bulletTime` sidecar；
2. 一份参考计划：图片角色、顺序、数量、模型上限及禁止用途；
3. 一个推荐镜头方案和一个无特效替代方案；
4. 可直接写入现有 25 字段的编译结果；
5. 最终提示词校验，包括一镜、主体时间、摄影机时间、入口/出口、音频和长度；
6. 降级标签：`continuous_orbit`、`guided_orbit`、`segmented_orbit` 或 `editorial_fake`。

## 硬规则

1. **主体时间和摄影机时间必须分层。** 主体可冻结/近冻结；摄影机必须沿声明路径持续运动。
2. **一次只承诺一个主运镜。** 默认连续环绕 90–120°，单次不超过 180°，不得把 360° 伪装成一次成功。
3. **零切点。** 连续方案必须 `cuts: 0`；分段拼接必须降级并明确标记，不能冒充同一镜。
4. **必须有入口和出口动作。** 前镜出口状态与后镜入口状态可追踪；无后镜也要写清本镜动作落点。
5. **运动分层。** 面部、身体和道具可锁；发梢、衣摆、环境粒子只允许合同声明的极慢运动。
6. **参考图按角色分工。** 人物全身/中景优先 `actionPose + front + threeQuarter + side`；近景用 `closeup + emotionCloseup + threeQuarter + actionPose`。更多图只有在增加新信息时才加入。
7. **参考视频只控制摄影机路径和时间相位。** 必须声明 `camera_and_timing_only`，禁止继承白模、网格、灰盒、灯光或背景。
8. **音频只写画内声。** 生成阶段禁止镜头外 BGM/配乐；声音由后期单独治理。
9. **技术参数留 trace。** 弧度、高度、速度进入合同；提示词正文写画面语言，不写 f 值、ISO 或快门。
10. **失败不盲重试。** 失败先改合同、重新过最终提示词门；没有新证据不得重复付费提交。

## 与现有岗位协作

| 岗位 | 责任 |
|---|---|
| `visual-director` | 判断叙事必要性，生成 `bulletTime` sidecar 和候选 |
| `cinematographer` | 把环绕、景别、焦段和运动模糊翻译成画面语言 |
| `prompt-fuser` | 将合同编译进现有 25 字段，不创建新供应商字段 |
| `continuity-reviewer` | 检查入口/出口、轴线、动作方向、服装与道具状态 |
| `field-inspector` | 最终提示词门：一镜、主体时间、摄影机时间、音频、长度 |
| `micromotion-stylist` | 主体冻结时返回 `not_applicable`；微动由合同运动层负责 |
| `render-operator` | 按模型能力选择 text / first-frame / reference-image / reference-video |
| `post-quality-inspector` | 核对主体低运动、摄影机视差、身份/服装稳定、零切点和音频策略 |

## 参考图数量判断

`4` 张是首版保守上限，适用于约 90–120° 单主体环绕。官方 Seedance 2.5 API 的图片参考上限是 30 张，活动页“50 个全模态素材”是图片、视频、音频合计上限。是否扩容取决于模型能力合同，不由 Skill 写死。

- 1–2 张：能锚正面/近景，但侧面、背面、遮挡和材质容易被模型猜。
- 3–4 张：人和常见产品约 90–120° 环绕的首选。
- 5–8 张：增加背面、动作、局部细节、产品结构。
- 更多：只有覆盖新几何/材质信息时使用；冗余会稀释注意力。

## 失败模式

| 症状 | 判据 | 处置 |
|---|---|---|
| 只有主体慢动作，镜头没动 | 摄影机视差低 | 改合同，明确 `camera_movement=continuous_orbit` |
| 静帧被推近 | 无真实视差 | 禁止提交；这不是子弹时间 |
| 人物自己转圈 | 身体动作时间层未锁 | 锁定 face/body，明确摄影机绕行 |
| 全场一起冻结 | 只有静帧没有空间观察 | 保留摄影机时间，添加合法极慢运动层 |
| 全景环绕后换脸/换衣 | 参考覆盖不足或动作超界 | 缩短弧度或增补角度图；不得盲重试 |
| 提示词超长 | 最终长度 >3000 | 回字段编译器合并，不截断正文 |
| 末尾出现配乐 | 音频策略冲突 | 生成阶段移除 BGM，由后期处理 |

## 验收证据

文本链路通过只说明合同、字段和门禁成立，不等于成片效果成立。成片还需要当前文件级证据：

- 任务 ID、提示词哈希、请求哈希、输入计划哈希；
- 零切点；
- 主体运动比例低；
- 摄影机视差有效；
- 身份和服装漂移低于阈值；
- 至少一个声明的发梢/衣摆/粒子微动层；
- 无非画内音乐；
- 艺术质量继续保持 `unverified`，直到实际看片。
