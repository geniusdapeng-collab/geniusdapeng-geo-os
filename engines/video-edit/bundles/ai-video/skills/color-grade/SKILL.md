# 调色执行纪律

## 适用场景

- 用户要求统一母版影调，执行一套明确 profile 或 LUT。
- 用户要求调整曝光、白平衡或饱和度，按明确参数进行本地加工。
- 用户要求多镜匹配，按指定参考计算校正量；没有调色请求时沿用原片。

成功渲染素材默认接受，进入正式后期。原片只读，保留原节目声音；历史品质失败原样留存，不能让同一成功镜头因组件变化再次付费。身份、服装、动作、画质、名义时长、嘴型、台词和声音品质均不触发默认模型、ASR、TTS、抽帧评分或人工放行。

## SOP：请求 → 加工 → 实际回执

1. 触发为明确调色请求；读取实际源文件规格、项目与镜号、来源 SHA256 和授权。回执记录输入字节；缺文件、越界或来源不符时失败，不能重新生成镜头来代替。
2. 把请求拆成校正、profile、LUT、强度。明确的 log/色域参数按支持的转换路径处理，不凭画面偏平猜 log。回执记录采用参数；未知 profile、缺 LUT 或强度越界在加工前失败。
3. 执行一次 `colorwrite.grade`；校正恒为 100% 生效，只有创意 look 按 `intensity` 混合。`auto` 和 `denoise` 仅在显式请求时执行其计算，不能变成源镜接受评审。
4. 明确多镜匹配时调用 `colorwrite.match`；参考/目标统计只用于求请求的变换，不抽成片验残差。每项有成功或错误结果，不能用全局成功掩盖缺失或失败的目标。
5. 核对真实工具完成、产物存在可读、当前 SHA256 与回执相符，并回读实际色彩标签。报告 `qualityReviewed=false`、`qualityScore=null`；没有测的品质项不写通过。

```bash
color-cli grade --in source.mp4 --out color-v2.mp4 --profile warm-film --intensity 0.75
color-cli match --ref hero.mp4 --in a.mp4 --in b.mp4 --out-dir matched-v2/
```

`colorwrite.best` 根据显式配方、题材或明确候选选一条实际方案并执行一次；不生成试渲候选池，不以改进分数决定接受，也不宣称已找到画面品质最优解。

## profile 选型与参数表

| 请求内容 | profile | 建议起点 | 工艺用途 |
|---|---|---|---|
| 叙事、情感 | `warm-film` | 0.70–0.85 | 暖调、轻提黑位 |
| 科普、产品说明 | `clean-bright` / `natural` | 0.60–0.80 | 以信息表达为主 |
| 技术、暗场界面 | `cool-technical` | 0.60–0.75 | 冷净风格 |
| 悬疑、严肃题材 | `moody-dark` | 0.50–0.70 | 压黑、去饱和 |
| 社媒、投流 | `high-contrast-social` | 0.70–0.85 | 高对比风格 |
| 复古、怀旧 | `vintage-fade` | 0.60–0.75 | 抬黑与去饱和 |
| 品牌统一 | `teal-orange` | 0.60–0.80 | 冷暖对照 |

上述为创作参考，用户可明确选择合法范围内其他强度；弱变化、黑帧、灰帧或模糊原片不因此被拒绝。

## 独立诊断目标值表（仅显式调用）

| 指标 | 参考区间 | 判读注意 |
|---|---|---|
| YMIN | 0–16 | 黑位创作参考 |
| YAVG | 80–140 | 夜景与高调场景不能用均值概括 |
| YMAX | 235–255 | 峰值白参考 |
| UAVG / VAVG | 128±6 | 中性色度参考 |
| SATAVG | 40–80 | 饱和度参考 |
| 肤色 | HSV 20–40° | 与 signalstats 的 HUEAVG 不是同一口径；显式 patch 优先 |

用户明确要求 `colorread.analyze`、scope 或 compare 时可独立出诊断；记录抽样时间、patch、置信度与未测项。诊断意见不删产物、不自动回上游、不触发付费重渲。原有场景切分、肤色、噪点和色带知识保留在 `library/color-kb/`。

## 参数边界与纪律

1. `intensity` 必须大于 0 且不超过 1；转换和校正不被 look 强度稀释。
2. profile 必须存在，LUT 必须实际可读，色域转换需要明确参数或明确元数据，禁止凭印象猜测。
3. 原片与输出不能相同，任何版本都禁止覆盖原片；路径、租户和许可必须合法。
4. 默认品质回执为未评审，禁止把 null 残差、空候选或空诊断打印成 0 分/满分。
5. 只按请求处理像素，不改叙事、字幕事实或人物身份；请求的配方更新不等于新镜头生成授权。

## 失败模式（症状 → 原因 → 处置）

| 症状 | 首查原因 | 处置 |
|---|---|---|
| 找不到输入或目标 | 实际文件路径与任务来源 | 返回 `not_found`，保留批次结果，不下载未知替代片 |
| 配方不存在/强度非法 | profile、LUT、`intensity` | 修正明确请求参数后另发一次请求，不自动试渲 |
| 输出路径被拒 | 允许目录、原片覆盖、权限 | 选合法新路径；不得放宽围栏 |
| FFmpeg/FFprobe 非零退出 | 实际工具 stderr、编码器、存储 | 保存真实错误与命令；停止该项，不伪造加工成功 |
| 批次有成功也有失败 | `results[].ok` 与实际文件 SHA | 完整返回所有项，CLI 非零退出；成功项保留，失败项指名 |
| 用户觉得风格太强/太弱 | 用户反馈与采用参数 | 形成明确本地返修请求，只改 look 参数，不重生成原镜 |

## 输出契约与知识库

回执包含输入来源、实际滤镜链、profile/LUT、强度、输出路径/大小/实际时长/SHA256、处理错误和未评审声明。选型说明保留题材、场景、情绪、平台；独立诊断另存，不能冒充默认完成条件。

知识入口：`library/color-kb/_INDEX.md`，CGRADE-001 肤色科学、CGRADE-005 示波器、CGRADE-006 白平衡、CGRADE-008 事故案例。历史 FC-COL-001 blend 权重、FC-COL-007 HSV/HUEAVG 混用用于工艺回归，不恢复自动品质闸。
