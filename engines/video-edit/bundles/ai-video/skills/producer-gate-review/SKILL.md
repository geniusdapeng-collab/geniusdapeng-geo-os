# 生成前监制与后期接受

## 适用场景

- G1 情报、G2 主题、G3 对齐、G4 PRD、G5 资产准备、G6 提示词、G7 预生产收口仍服务实际新生成任务。
- G8 付费提交的授权、租户、支付、预算、用途许可保持；G9 发布与 G10 评论回复按原外发围栏执行。
- 成功渲染镜头与 compose、color、subtitle、mux、danmaku、bgm、sfx、cover、master 属于后期默认接受路径。
- 混合复用与新生成时，仅尚未生成的已登记镜头进入生成前准备；已完成镜头不重新绑定定妆照或编译品质合同。

## 一、决策方法与阶段边界

1. 先确定是“即将花钱生成”还是“已经成功生成进入后期”。不能把历史品质拒绝误当供应商失败。
2. 生成前检查真实内容、授权资产、预算与审批；空内容、占位符、缺必需授权等按现有门明确停止。
3. G5 与绑定清单只约束实际新生成的人物任务。已成功镜头无需为了后期补旧人像、旧商品照片或旧提示词工位依赖。
4. 后期核对供应商真实成功任务、项目、镜号、冻结来源与当前字节，再执行请求操作；身份、服装、设备外观、环境、动作、嘴型、台词和画质不再复核。
5. 没有模型、ASR、额外 TTS、抽帧审查或人工品质放行；品质意见不能触发自动重渲或重做。

## 二、前置校验与参数边界

| 项目 | 真正适用阶段 | 可判定证据 / 失败行为 |
|---|---|---|
| 租户与项目 | 全部实际操作 | 当前身份、项目归属、受控路径不符必须停止 |
| 权限、许可与预算 | 新生成及实际外发 | 当前授权与围栏回执；不得绕过花钱门 |
| 准备正文 | 实际新生成 | 读取正文而非只给路径；空文本与占位符按前置门处理 |
| 供应商成功 | 已渲染镜头接受 | 真正 taskId、终态 done/completed 与无 genuine failure 标志 |
| 来源与字节 | 复用与后期 | 非空源输入哈希、当前文件 SHA-256、血缘与镜号绑定 |
| 请求产物 | 后期结束 | 实际输出文件、画布、指定轨道与执行退出码 |

禁止拿原片分辨率、FPS、实际片长、音轨缺失或内容品质作为后期二次评分。后期可按请求画布实际规范化；文件损坏、元数据不可读、处理失败和请求输出缺失仍是明确技术错误。

## 三、SOP

1. **触发**：计划存在待生成镜头。读取原始登记清单与 pending 镜号。**回执**：preRenderShotIds、需求版本与授权引用。**失败**：空、重复、不在原始清单的镜号应停止；不得扩大成已完成镜头复审。
2. **触发**：需要新提交。按实际门执行准备与付费前审查。**回执**：gate、via、model、issues、suggestions 与当前版本。**失败**：真实授权或准备门拒绝停止提交，禁止盲目重试付费。
3. **触发**：真实任务已成功、文件存在。验证供应商与来源字节，追加独立 rendered-source 接受回执。**回执**：任务、源输入、artifact SHA-256、原始事实哈希。**失败**：真实任务失败、缺来源或字节被替换停止；不伪造质量通过。
4. **触发**：执行正式后期。按明确请求各做一次。**回执**：真实产物、执行日志，qualityReviewed=false、score=null、rerun=false。**失败**：工具、文件与请求出口错误记录后传播，不能以跳过失败产物完成交付。

## 四、输出契约与证据口径

- 后期 verdict 仍绑定原始事实与合同哈希，不重新解析创作品质字段来放行；未测品质分为 null。
- 历史品质失败事件只增不改；接受是新来源回执，不把旧记录改成 approved。
- 全链阶段日志位于 `<work-dir>/logs/<项目>/stages.jsonl`，另有 stage-summary；复用计数与实际 invoked 不混记。
- 当前文件哈希和工具日志可证明执行；不能由 approved=true 文本或旧成功标记单独证明当前来源。
- 已完成素材因组件变化、旧评分或旧人工 canary 失败不重新付费；供应商状态与来源仍需真实有效。

## 五、失败诊断（原因 → 处置）

| 症状 | 检测器 / 原因 | 处置 |
|---|---|---|
| 后期被要求补人像、商品或新提示词 | 已接受镜号又进入准备路径 | 限定 pending-only，已完成镜头直接后期 |
| 旧品质失败导致重复提交 | 只看历史 ok，未识别真实 task/字节 | 验证供应商与当前来源，追加接受回执；原历史保留 |
| 供应商 failed 却被采用 | 仅检查文件存在或 legacy quality 标志 | 停止；保留原失败码与任务引用，禁止默认复渲 |
| 来源输入或原片被替换 | sourceInputs / lineage SHA-256 不匹配 | 停止复用并指出被改文件，不用新空血缘遮盖旧输入 |
| 模型不可用 | 实际新生成前门需要模型 | 按原准备门失败策略处理；不能在后期因此转人工品质阻塞 |
| 后期工具非零退出 | stderr 与执行回执 | 记录真实失败并停止出口，不给缺失变体或字幕记完成 |

## 六、未做的判断

后期默认不判断人物像不像、服装是否统一、设备型号、画面是否写实、动作是否自然、声音是否好听或是否完整念出每句台词。明确用户返修可改变某个后期层或启动经授权的新生成，但不能由本工位自动推导付费重做。
