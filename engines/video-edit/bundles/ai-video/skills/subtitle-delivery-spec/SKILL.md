# 字幕交付规范

## 交付物与默认路径

成功渲染源镜直接进入正式后期并保留节目声音。字幕来自明确提供的文本与时间轴，没有听译请求时不做 ASR；原片画质、台词或旧字体/版式品质失败不要求重新生成镜头。

| 交付物 | 默认内容 | 证据 |
|---|---|---|
| 新成片或软字幕版本 | 实际请求的烧字/封装产物 | 文件路径与 SHA256 |
| 字幕方案 | 字体、字号、描边、边距、ASS 样式与事件 | 实际计划/ASS 文件 |
| 文字/时间轴回执 | 请求条目、采用条目和明确变更 | 真实数量与起止 |
| 扩展轨回执 | 弹幕、贴纸、卡拉OK、双语的请求参数 | 实际 placements/timing/密度设置 |
| 抽帧品质证据 | 默认不采集 | 仅明确独立诊断时提供 |

## SOP

1. 触发为明确字幕或扩展文字请求；核对文本、时间轴、源片 SHA256、字体许可和输出路径。空/错误形状、非法时间和权限不符明确失败。
2. 按请求选择随包字体及平台参数，生成 ASS 计划。默认保留所有文本和弹幕条目；不能默设 20 字或并发 8 条限制。
3. 执行一次烧字，或在软字幕路径 copy 原视频/音频轨。原母版只读，禁止让字幕操作重生成画面、配音或隐式听译。
4. 核对实际文字事件与请求时间轴、字体解析、产物流和当前 SHA256；品质未评审，不能宣称对比度、可见性或画质通过。
5. 用户明确要求密度/长度限制时才按该参数抽稀或拒绝，并报告原条数、保留条数与限制；用户返修改文字层，不重做未点名镜头。

## 版式工艺参考表

| 项 | 建议/原工艺参考 | 当前边界 |
|---|---|---|
| 字幕字号 | 短边 3.8%–7.5% | 创作参考，不默认成片量测闸 |
| 标题字号 | 短边 8.5%–16% | 请求参数与字体能力决定 |
| 单行汉字 | 竖屏 18 / 横屏 22 | 推荐断行，不截断内容 |
| 安全边距 | 短边至少 2.5% | 平台设计参考，不默认像素审查 |
| 弹幕密度 | 用户可显式设并发上限 | 默认无限制，九条同窗保留九条 |
| 弹幕长度 | 用户可显式设正整数上限 | 默认无 20 字上限 |
| 贴纸时窗 | 原推荐 1.5–3s | 请求/接口合法性保留 |
| 卡拉OK | 逐字时长对应事件时窗 | 真实文本与显式/均分口径留痕 |

## 参数边界与纪律

1. 字体必须存在且许可覆盖用途（G-SUB5），字体缺失不能静默删字。
2. 原片只读；软字幕禁止不必要视频重编码，烧字写新文件，母版保持干净。
3. 时间轴和数组形状必须合法；未知模式/错误参数明确失败，不伪造已添加文字。
4. 只有显式有效正整数 `max_chars` / `max_concurrent` 才施加对应限制，null/布尔/非法值不能悄悄变默认限制。
5. 既有 CJK 标点格式化与内容截断不同；采用的格式化规则留痕，数字/英文/文本条目不因默认质量判断被删除。
6. 不默认抽帧做对比度/墨迹/可现度/清晰度评审；未测 quality 项为 null/未评审。

## 失败与用户返修归因

| 症状 | 原因/首查 | 处置 |
|---|---|---|
| ASS/SRT 时间非法 | start/end/条目形状 | 返回请求错误，保留原片，不猜时间 |
| 字体缺字或文件缺失 | 字体解析和许可 | 指名缺字体/字符，不静默丢字 |
| FFmpeg/libass 加工失败 | 实际日志、编码器和路径 | 保留真实失败，不将它包装为品质分低 |
| 默认长弹幕/九条同窗丢失 | 隐式 max_chars/max_concurrent | 默认不得截断抽稀，按完整请求生成 |
| 用户说字挡 UI/太小 | 明确用户反馈与版式参数 | 新本地文字请求，修改位置/字号 |
| 用户说时间或翻译不对 | 明确时间轴/文本变更 | 记录新条目版本；不自动 ASR 或重配原声 |
| 上游黑帧/低分辨率/已有硬字 | 成功原片实际内容 | 默认继续请求加工，意见只单独记录，不重渲 |

## 版本、回执与接口

命名 `<项目>-vN-<平台>.mp4/.ass/.srt`，输出只增不覆盖。清单记录 source/output SHA256、font/编码器/采用样式、条目时间轴、明确抽稀或格式化及处理错误。文字不属于画面生成授权；合规、实际缺件与处理失败继续明确。
