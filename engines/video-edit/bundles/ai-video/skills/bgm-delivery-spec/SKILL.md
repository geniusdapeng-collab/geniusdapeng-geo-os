# 配乐交付规范

## 默认声音与请求边界

成功渲染源镜默认直接进入正式后期，保留原片完整节目声音。无明确配乐请求时沿用原声，不测人声活动、底噪、响度、余量或安全窗口，也不启动分离、ASR、TTS或模型复评。静音/无音轨原片照常进入请求后期；加工可按同一时间轴插入真实静音床，不能伪造独立对白来源。

明确加音乐时，默认以实际原节目为来源并执行一次混音。`audio_stems` 显式提供时必须具备真实四角色清单、来源签章、租户与授权，不能将原节目声称为已分离对白。`replace-bed` 需要明确独立对白来源，`music-only` 需要丢弃原声授权；直接接受旧镜头不放宽这些权限。

## 工艺参数与交付规格

| 项 | 当前请求口径 | 说明 |
|---|---|---|
| 音乐电平 | 常用 -26 / -22 / -19dB | 口播/广告/促销配方参考，合法范围按接口 |
| 单次归一目标 | 默认混音配方 -14 LUFS / -1 dBTP | 实际请求滤镜参数；不两遍测量复检 |
| 采样率/声道 | 当前混音 48kHz 立体声 | 实际产物规格留痕 |
| 成片编码 | 视频轨 copy，音频 AAC 192k | 不重生成画面 |
| 音乐时长 | 按实际源片时间轴铺满 | 短曲按请求循环，长曲按选段/尾奏处理 |
| 命名 | `<项目>-vN-bgm.mp4` | 新文件，原片只读 |

## SOP

1. 触发为明确 BGM 请求；核对源片 SHA256、曲目/配方、许可、输出新路径。回执记录当前输入；实际缺件或版权不合规时失败，不静默换曲。
2. 根据请求及曲目元数据选一条配方/曲目；`compose-only` 本地作曲不联网。明确外部来源政策才走对应来源，不能为品质评分试渲候选或退回供应商。
3. 按请求 policy、音乐电平、让位与选段执行一次实际混音；实际工具非零、签章不符或没有产物保持失败。不按声音分数自动降 3dB 重试或按原声降级。
4. 核对输出当前 SHA256、实际流、视频/音频加工完成、曲目来源字节及署名要求。报告 `qualityReviewed=false`，质量分 null。
5. 用户明确反馈“音乐太响/换曲/不配乐”时形成新本地请求，修改相应音频层；原镜头和历史失败记录保持原样。

## 选段与派生纪律

- `section` 的 full/auto/climax/calm 或显式起止按当前音乐选择实现与请求执行；不分析原片对白峰值来评审源质量。
- 平台画幅版本可从已配乐母版派生；明确多风格变体可各执行声明的配方一次，保留曲目/参数差异。
- `targetLufs`、`truePeak` 为请求滤镜参数，回执不能把它们当实测值。
- 不默认生成波形、卡点达标率、可闻度或人声余量证明；独立诊断才保存这些证据。

## 参数边界与围栏

1. 原片只读（G-BGM2）；曲目、素材、租户及作用域必须匹配。
2. 音乐许可与署名必须真实有效（G-BGM5），不可静默替换版权来源。
3. `music-only` 不能默认启用；`replace-bed` 不能从未分离节目推断对白角色。
4. G-BGM3 只保留实际加工/源授权失败，不恢复默认响度、峰值、余量或质量分数闸。
5. 显式分轨提供则必须有效；形状错误、来源未核实或签章失败不能降为原声默认路径。

## 失败模式（症状 → 原因 → 处置）

| 症状 | 原因/首查 | 处置 |
|---|---|---|
| 找不到曲目/配方 | 实际曲库 ID、文件和 SHA | 指名缺件，不悄悄换曲 |
| 曲目无许可或签章不符 | 许可、source receipt 与租户 | 授权失败，停止混音 |
| 明确 replace-bed 没有独立对白 | 四角色真实来源 | 返回来源未核实，不冒充分离 |
| FFmpeg 执行失败/输出不可读 | 命令、stderr、文件权限 | 保留真实失败，不能按原声复制冒充完成 |
| 用户说音乐盖字/听不见 | 用户反馈与原电平参数 | 形成明确调电平请求，不自动品质重试 |
| 用户说风格不符/卡点不齐 | 请求题材、配方和剪辑点 | 修改明确配方/速度，保留历史版本 |
| 原声静音/已有音乐/底噪高 | 原节目实际音频 | 默认接受，不自动决定不配或重新生成 |

## 回执与知识引用

必需：输入及曲目 SHA256、许可与作用域、采用配方/选段/滤镜参数、实际输出路径/规格/SHA256、真实处理次数和错误。未测 loudness、peak、margin、presence、beat alignment 等保持 null；不以目标参数冒充已测达标。

知识入口：`library/bgm-kb/_INDEX.md`，SCORE-004 平台响度和 SCORE-007 混音诊断知识。它们支持明确独立诊断与用户返修，不接回成功素材的默认接受条件。
