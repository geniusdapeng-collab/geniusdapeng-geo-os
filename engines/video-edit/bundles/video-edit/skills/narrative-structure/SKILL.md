# 叙事结构与评审（narrative-structure v2）

> **创作前提（先读）**：`docs/video-edit-creation-doctrine.md`。本技能负责三件事：
> ① 创作模板（short_style_definer：受众/目标/语言/时长/视角/字体，每项带 comment 与 reason）；
> ② 故事大纲（故事脉络 500–700 字 + 情感曲线 3–4 节点 + 情绪主线 + 一句核心创作指令）；
> ③ 制作剧本（场景 ×N：时间连续覆盖 / 素材来源 / 故事线 / 知识点或痛点 / 情绪主线 / 叙事描述 / 详细故事 400–700 字 / 剪辑建议）。
> 场景数与每场景镜头密度按**节奏档案**（documentary / vlog / fast_cut / information）的默认值走，偏离只出咨询项。

## 1. 从"大纲"到"施工图"

旧链路产出的是"故事脉络 500–700 字 + 情感曲线 3–4 个节点"——它是给人读的，不是给剪辑执行的。
v2 要求同时产出两份东西：

1. **可执行 beat 表**：每个 beat 有意图、目标秒数、情绪目标与强度、绑定的素材 id 与高光/关键帧 id。
2. **曲线与节奏图**：情绪强度是 0–1 的分段数值（可画折线）；节奏是"平均镜头时长 + 每分钟切点数"的分段表。

> 判断标准：把 beat 表交给剪辑指导，对方不需要再问"这里你想让我表达什么"，就能直接排时间轴。

## 2. 结构模板（默认建议，可覆盖）

| 模板 | 骨架 | 适用 |
|---|---|---|
| `hook_cta` | 钩子(0–3s) → 情境 → 冲突/转折 → 解决 → 落点 + CTA | 营销/种草/知识 |
| `mini_drama` | 定调 → 铺垫 → 触发 → 升级 → 高潮 → 余韵 | 剧情/情绪 |
| `essay` | 引子（一个画面/一句话）→ 展开（2–3 段）→ 收束（回到引子） | 文艺/纪录/独白 |
| `observe` | 现象 → 细节证据 1/2/3 → 归纳 → 反问 | 社会观察/评论 |
| `process` | 目标 → 步骤 1..n → 结果 → 复用建议 | 教学/教程 |

## 3. 情绪曲线与节奏图（必须可执行）

- `emotionCurve[]`：`{ t, intensity, label }`，至少 5 个点，含 1 个峰值与 1 个回落点；相邻点强度差 >0.45 时必须在 beat 说明里给出触发事件。
- `tempoMap[]`：按 beat 段给 `avgShotSeconds` 与 `cutsPerMinute`；开场段默认 1.2–2.2s/镜（钩子期可以更短），情绪段可放长到 3–6s/镜。
- 数值必须与素材能力相符：素材里没有足够的短镜头时，不得写"快切"却无镜头可用；缺料要标注缺口。

## 4. 四视角评审（与生成分离）

评审只看候选、素材证据与平台事实，不给"我觉得"。四个视角各自 0–10 分：

| 视角 | 看什么 | 典型扣分 |
|---|---|---|
| 叙事 `narrative` | 因果是否成立、转折是否有触发、结尾是否落得住 | 只有情绪没有推进；结尾空转 |
| 情绪 `emotion` | 曲线是否有起伏、峰值是否有支撑、能否引发共鸣 | 全程同一强度；靠煽情台词撑情绪 |
| 平台 `platform` | 前 3 秒钩子、时长带、画幅与安全区、完播设计 | 开头 5 秒还没进入主题；竖屏按横屏剪 |
| 执行 `feasibility` | 素材是否够用、镜头是否可用、工期与成本 | 需要素材里不存在的镜头；依赖不可用的特效 |

**总分** = 0.30·叙事 + 0.30·情绪 + 0.20·平台 + 0.20·执行（可按项目覆盖，覆盖需记录理由）。
评审结论必须附"为什么扣分"的具体理由，供创作者修正，而不是只给数字。

## 5. 提示词正文（可直接投喂，v2）

```text
你是"叙事架构师"。任务：把选定创意落成可执行叙事方案，并对全部候选给出四视角评审。

【输入】
- 选定创意（含差异化标签、开场/转折/结尾设计、素材映射）：{{ chosen_candidate }}
- 全部候选：{{ creative_set }}
- 素材证据池（含时长、情绪、可用性、高光与关键帧）：{{ material_index }}
- 目标：时长带 {{ duration_band }}｜平台 {{ platform }}｜期望感受 {{ emotion_goal }}
- 允许的结构模板与默认节奏：{{ structure_templates }}

【硬性纪律】
1. 每个 beat 必须绑定真实素材 id（shot:/highlight:/keyframe:），无素材支撑的段落必须写进 risks 并给替代方案。
2. 情绪强度为 0–1 数值；节奏为具体秒数与每分钟切点数；禁止只写"节奏紧凑""情绪饱满"。
3. 总时长必须落在目标时长带内（beat 目标秒数之和处在该区间）。
4. 评审与生成分开：评审段落只依据候选文本与素材证据打分，禁止引入输入之外的信息。

【输出 JSON】
{

    "slot": "T01",
    "structure": "hook_cta",
    "narrativeVoice": "first_person",
    "beats": [{ "beatId": "b1", "name": "钩子", "intent": "", "targetSeconds": 3,
                "emotionTarget": "", "intensity": 0.7, "materialRefs": ["shot:xxx"], "highlightRefs": [], "keyframeRefs": [] }],
    "emotionCurve": [{ "t": 0, "intensity": 0.3, "label": "开场" }],
    "tempoMap": [{ "fromBeat": "b1", "toBeat": "b2", "avgShotSeconds": 1.8, "cutsPerMinute": 33 }],
    "bgmPlan": { "needed": true, "style": "", "energyCurve": "", "beatSync": true },
    "risks": ["素材缺口/授权缺口/时长缺口"]
  },
  "review": [{ "slot": "T01", "scores": { "narrative": 8.5, "emotion": 9.0, "platform": 8.0, "feasibility": 7.5 },
               "total": 8.4, "notes": "扣分理由（具体到 beat）" }],
  "recommendedOrder": ["T03", "T01"]

```

## 决策原则（含阈值与失败关闭）

1. **每个 beat 必须有素材证据**：无素材支撑的段落只能进 `risks` 并给替代方案，不得写进主结构。
2. **数值化硬约束**：情绪强度 0–1、节奏为秒数/每分钟切点数、总时长落在时长带（误差 ≤5%）；形容词不计入。
3. **评审与生成分离**：评审只依据候选与素材证据；同一视角出现全候选同分即视为无效评审，重做。
4. **失败关闭**：素材缺口、授权缺口、时长缺口任一存在时，方案状态为"待补料"，不得标为可执行。
5. **结构服务表达**：模板只是默认建议；为表达让路时可以换结构，但必须写明理由与对时长的影响。

## 打法库（场景 → 动作序列 → 判据）

- **主线·结构落表**：选模板 → 排 beat → 分配秒数 → 绑素材 id → 画曲线与节奏图（判据：时长带命中 + 素材映射 100%）。
- **分支·素材不足**：先做"素材减法"（合并同义 beat），再列补拍/补料清单（判据：缺口清单可执行、含规格）。
- **分支·开头不抓人**：把最高分高光提到 0–3s，用悬念句或结果前置（判据：钩子 beat 绑定的高光分 ≥0.7）。
- **分支·多平台适配**：同一结构派生横/竖两版节奏（竖版提速 15–25%），共用叙事骨架（判据：两版时长各自命中平台带）。

## SOP（每步带触发/回执/失败路径）

1. 触发（创作方向 G-ED7 已确认）→ 读候选与素材池 → 回执：`story_plan`（beat/曲线/节奏/映射）；失败：素材 id 解析失败即回退该 beat 并标注，不编造素材。
2. 触发（结构初稿）→ 四视角评审 → 回执：评审矩阵（分数 + 扣分理由 + 推荐序）；失败：评审缺理由或全同分即视为无效，重跑评审。
3. 触发（评审通过）→ 时长与可行性复核 → 回执：时长带命中报告 + 缺口清单；失败：超出时长带 >5% 即回退重排，不带着缺口进剪辑。

## 关键指标（含基准与护栏）

| 指标 | 口径 | 基准/阈值 | 类型 | 来源 |
|---|---|---|---|---|
| 时长带命中率 | 落在目标带内的方案 / 方案总数 | ≥95%（误差 ≤5%） | 护栏 | 时长核算 |
| 素材映射率 | 有素材 id 的 beat / 全部 beat | 100% | 护栏 | 结构校验器 |
| 评审区分度 | 同一视角不同候选的分差 / 视角数 | 任一视角不全同分 | 质量 | 评审矩阵 |
| 缺口可执行率 | 带规格与替代方案的缺口 / 缺口总数 | 100% | 质量 | 缺口清单抽检 |
| 结构复用率 | 同一骨架派生平台版本数 / 方案数 | ≥1（多平台时 ≥2） | 成本 | 平台适配回执 |

## 失败模式（症状 → 检测器 → 处置）

| 症状 | 检测器 | 处置 |
|---|---|---|
| 剪出来平 | 曲线无峰值或峰值无素材支撑 | 检查峰值 beat 绑定的高光分；无高光支撑时明确降级为平缓叙事 |
| 时长差 20% 以上 | beat 秒数为估算 | 用素材真实时长反推可承载秒数，重新分配 |
| 评审全 9 分 | 评分未校准 | 强制扣分理由；同视角不允许全候选同分（区分度检查） |
| 结尾空 | 收束 beat 无落点 | 收束必须回到开场母题或给明确行动建议，禁止空镜凑数 |
| 方案很美但剪不出来 | 未绑定素材与时长带 | 每个 beat 强制 id + 目标秒数，超能力的标注缺口 |

## 6. 自检清单

- [ ] beat 目标秒数之和落在时长带内；无超时/欠时
- [ ] 每个 beat 有素材 id；缺口已列入 `risks` 并给替代方案
- [ ] 情绪曲线含峰值与回落，数值与 beat 一致
- [ ] 节奏数值与素材实际能力相符（不是口号）
- [ ] 四个评审视角都有分与理由；总分算法与权重可复算
- [ ] 没有引入候选与素材之外的信息

## 7. 首尾节奏决策路由（2026-10-15）

决策在理解事实与故事结构确定之后、最终剪辑和字幕之前。故事岗同时保存供 `edit:rhythm --story` 读取的顶层 `rhythm` 对象，不用自由文本“快一些”替代可执行目标。

```json
{
  "rhythm": {
    "mode": "auto",
    "opening": { "purpose": "hook", "energy": 0.8, "reason": "先展示三个有证据的动作细节" },
    "ending": { "purpose": "reflection", "energy": 0.3, "reason": "保留人物最后一句完整表达" },
    "durationBand": { "minSeconds": 28, "maxSeconds": 32 },
    "clipCount": 3,
    "clipSeconds": 0.8,
    "minLandingSeconds": 1.5,
    "beatSync": false
  }
}
```

开头 `hook/preview/action`、结尾 `recap/payoff/action` 且 energy≥0.6 才有自动提速意图；`dialogue/reflection/natural` 保持故事需要的停留。目的与理由来自本片，不能每片复制示例。实际能否快切由安全区间、正文保护、时长及音乐测量再决定；可回退单端或自然并说明。用户明确要求强制时选对应模式，条件不足返回可修正错误。音乐卡点是可选能力，动作剪辑可无 BGM；BPM 不是成片落点证据。
