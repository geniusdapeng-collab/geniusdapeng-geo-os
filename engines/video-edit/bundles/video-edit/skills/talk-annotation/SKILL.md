# 口播点睛层（talk-annotation v1）

> 口播的信息靠"说"，记忆点靠"看"。点睛层的目标是：**观众看完能带走三个记忆点**。
> 纪律一句话：不遮挡、不刷屏、不编造、不重复。

## 适用场景

- 口播里有知识点、数字、步骤、结论，希望观众"看得见、记得住"；
- 需要章节条让长口播可以跳着看（短视频同样有收益：完播与回看）；
- 需要弹幕/贴纸营造氛围，但要避免刷屏压字幕。

## 输出契约

产出 `talk_annotation`（执行器 `pnpm edit:talk-annotate`）：

| 产物 | 内容 | 交接 |
|---|---|---|
| 弹幕条目 | 文本（≤14 字）、时间、模式（顶部/滚动）、颜色、理由 | `pnpm edit:danmaku --items danmaku.json` |
| 贴纸卡 | 类型（数字/清单/金句）、文本、进出时间、位置、安全区约束 | 后期贴纸工位 |
| 章节条 | 标题（≤14 字）、起止时间 | 后期章节/进度条工位 |
| 回执 | 数量、密度、遮挡自检、告警 | 交付清单 |

**时间口径**：所有时间都是**成片主轨时间**；被剪掉的句子不生成点睛（源时间 → 主轨时间映射失败即跳过）。

## 3. 抽取口径（从逐字稿里"挑"，不是"写"）

| 类型 | 判定 | 处理 |
|---|---|---|
| 金句/结论 | 含"记住/关键/本质/核心/我告诉你"等结论词 | 顶部弹幕（≤14 字）+ 金句贴纸卡 |
| 数字/量词 | 含数字或中文量词（三个/两次/10 分钟） | 数字贴纸卡（数字单独立起来） |
| 步骤/列举 | "第一/第二/第三""首先/其次/最后" | 清单卡（按步骤顺序） |
| 氛围句 | 强语气、节奏感的口语句 | 滚动弹幕 |
| 与字幕重复的整句 | 与字幕文本完全一致 | **不发射**（弹幕是补充，不是复读机） |

## 4. 密度与安全区（硬口径）

| 项 | 阈值 | 说明 |
|---|---|---|
| 弹幕密度 | ≤6 条/分钟 | 超限收手，剩余知识点改贴纸或章节 |
| 前 2 秒留白 | 0 条 | 钩子画面必须干净 |
| 顶部弹幕位置 | 顶部安全区 | 避开人脸区与字幕带 |
| 贴纸位置 | 顶部左/右 | 单卡停留 3.2s（够读一遍） |
| 章节长度 | ≥3s | 太短不生成 |

## 决策原则（含阈值与失败关闭）

1. **逐字不编造**：文案逐字取自逐字稿；稿里没有的数字/结论一律不出现（G-TK1）。
2. **不遮挡优先于不刷屏**：任何点睛元素不得压字幕带与人脸区；冲突时宁可不加（G-TK8）。
3. **密度先行**：先按 ≤6 条/分钟算配额，再挑最有价值的条目；不做"有多少飘多少"。
4. **时间映射失败即跳过**：源时间落在被删区间时不生成（不做近似对齐），并把跳过原因写进回执。
5. **失败关闭**：章节无一条生成或弹幕全部被过滤时如实报空并说明原因，不硬塞内容。

## 打法库（场景 → 动作序列 → 判据）

- **主线·知识点弹幕**：扫逐字稿找锚点 → 去重与配额 → 生成弹幕与贴纸 → 安全区自检 → 交接渲染（判据：密度达标、无遮挡、文案逐字一致）。
- **分支·纯氛围口播（无知识点）**：用章节条 + 少量滚动弹幕承接口语节奏，不强凑知识点（判据：弹幕条目不含编造内容）。
- **分支·长口播（>3 分钟）**：章节条按话题块生成，弹幕集中在知识点密集段（判据：章节 ≥3s、弹幕分布不集中于前 30 秒）。
- **分支·垂类术语多**：术语用贴纸卡单独展示（≥3.2s），弹幕只放结论（判据：单卡停留时间与术语字数匹配）。

## SOP（每步带触发/回执/失败路径）

1. 触发（剪取台账与时间轴锁定）→ 生成章节/弹幕/贴纸候选 → 回执：候选项与来源句；失败：源时间无法映射到主轨即跳过该项并记录，不近似对齐。
2. 触发（候选就绪）→ 密度裁剪与去重 → 回执：条目清单与配额使用情况；失败：超限即按价值降序裁剪，不做"全部保留再删"的隐性动作。
3. 触发（条目确认）→ 安全区自检与交接渲染 → 回执：遮挡检查结果 + 渲染回执（产物指纹）；失败：越界即打回重排，宁可少一条不留遮挡。

## 关键指标（含基准与护栏）

| 指标 | 口径 | 基准/阈值 | 类型 | 来源 |
|---|---|---|---|---|
| 密度合规率 | 每分钟弹幕 ≤6 条 | 100% | 护栏 | 点睛回执 |
| 逐字一致率 | 与逐字稿逐字一致的点睛条目 / 全部条目 | 100% | 护栏 | 逐字比对 |
| 遮挡冲突数 | 与字幕带/人脸区冲突的条目数 | 0 | 护栏 | 安全区自检 |
| 章节可读性 | 标题 ≤14 字且长度 ≥3s | 100% | 质量 | 章节清单 |
| 去重率 | 与字幕完全一致的整句被过滤的比例 | 100% | 质量 | 去重记录 |

## 失败模式（症状 → 检测器 → 处置）

| 症状 | 检测器 | 处置 |
|---|---|---|
| 弹幕压字幕/压脸 | 安全区自检 | 换位置或删该条；不解释、不将就 |
| 画面太吵 | 密度 >6 条/分钟 | 按价值裁剪，剩余内容改贴纸/章节 |
| 弹幕写着稿里没有的话 | 逐字比对 | 删除该条并复核抽取口径（G-TK1） |
| 弹幕与字幕重复 | 文本比对 | 过滤重复项，保留补充信息 |
| 章节与内容不符 | 人工抽看 | 用话题块标题回填，不另起标题 |

## 5. 自检清单

- [ ] 每条弹幕/贴纸文案都能指回逐字稿的具体句子
- [ ] 密度 ≤6 条/分钟，前 2 秒无弹幕
- [ ] 顶部弹幕与贴纸都在顶部安全区，未压字幕带与人脸区
- [ ] 章节条 ≥3s 且标题 ≤14 字
- [ ] 与字幕完全重复的整句已被过滤
