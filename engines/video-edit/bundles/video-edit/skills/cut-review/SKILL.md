# 剪辑质检与返修单（cut-review）

> **质检新增两类项**：① 三字段核对（画面文字 / 人声 / 环境音是否采集、通道是否如实标注，
> 用 `pnpm edit:verify -- --analysis <probe.json>…`）；② 字幕规则校验（≥2s / VMG / 字数带 / 无标点 / 结尾话术位，
> 用 `pnpm edit:subtitle`）。**节奏档案**（pacing profile）不达标只出咨询项——它是体裁默认值，不是硬闸。

## 1. 四类检查（按硬闸强度分层）

| 类别 | 检查项 | 强度 |
|---|---|---|
| 合法性 | 主轨连续、无重叠、总时长一致、片段时长区间、转场参数合法、枚举合法 | **硬**（不通过即阻断） |
| 可执行性 | 素材存在且可用、授权覆盖当前用途、源轨 in/out 在素材时长内、速度与帧率可行 | **硬**（不通过即阻断） |
| 连续性 | 越轴、视线匹配、景别跳变、光线与色温跳变、音量跳变、字幕安全区 | 咨询（给出建议，人决定） |
| 合规 | 价格口径、地域/品牌事实、平台规格、账号禁忌清单 | 硬（事实类） |

> 纪律（T-2026-0930-0015）：**审美口径不得写成硬闸**。"节奏不够快""调性不符""画面不够美"只能作为咨询项。

## 2. 连续性检查清单（咨询项，逐条给证据）

1. **越轴**：相邻两镜主体运动方向是否相反（左→右 接 右→左）；有则提示"可能越轴"，并给替代镜头或插入中性镜头的方案。
2. **视线匹配**：人物看向画面外时，下一镜应在对应方向给出被看对象（或用视线方向的空镜过渡）。
3. **景别跳变**：同机位相邻镜景别差异 <1 级（如中景接中近景）易产生"跳"感；建议改为硬切到不同角度或加大景别差。
4. **光线/色温**：相邻镜光线方向与色温差异过大时提示（连续场景优先保持同一光位与色温基准）。
5. **音量**：相邻段平均响度差 >6 dB 时提示加过渡或做响度对齐。
6. **安全区**：字幕与人脸、平台 UI 区域（标题带/点赞区）冲突时提示换位。

## 3. 返修单格式（必须可执行）

每条不合格项给出：

```
{ "segmentId": "seg-007", "field": "transitionIn.type", "current": "wipe",
  "problem": "从情绪段切入信息段使用划像，视觉上打断情绪", "action": "改为 cut，并把 0.4s 的停顿留给环境声",
  "severity": "advisory|hard", "evidence": "帧 00:01:12.400 前后 6 帧" }
```

- `action` 必须是"改成什么"，不是"建议优化"。
- `severity=hard` 只用于事实类；审美类一律 `advisory`。

## 4. 质检报告模板

```json
{
  "checks": [
    { "id": "timeline.continuous", "pass": true, "hard": true, "detail": "主轨 0–42.6s 连续" },
    { "id": "timeline.noOverlap", "pass": true, "hard": true, "detail": "同源片段最小间隔 2.1s" },
    { "id": "duration.target", "pass": true, "hard": true, "detail": "42.6s / 目标 40–45s" },
    { "id": "material.rights", "pass": true, "hard": true, "detail": "全部素材 cleared + timeline-source" },
    { "id": "continuity.eyeline", "pass": false, "hard": false, "detail": "seg-012 视线朝左，下一镜主体在左" }
  ],
  "fixes": [{ "segmentId": "seg-012", "field": "sourceIn", "action": "改用 shot:xxx（同场景右侧机位）", "severity": "advisory" }]
}
```

## 决策原则（含阈值与失败关闭）

1. **硬闸只保留事实类**：只有合法性/可执行性/事实合规三类能阻断；审美类一律 advisory（T-2026-0930-0015）。
2. **每条不合格必须可执行**：给出"哪一段、哪个字段、改成什么"；无法执行的建议不得进返修单。
3. **检查有证据**：结论必须附帧号/字段值/素材 id，无证据的结论不得打回。
4. **失败关闭**：素材缺失、授权不覆盖、时间轴断裂即判 hard 失败，不因"看起来还行"放行。
5. **咨询项不阻断交付**：越轴/景别/光线/音量只在报告里提示，由人决定是否改。

## 打法库（场景 → 动作序列 → 判据）

- **主线·四类检查**：合法性 → 可执行性 → 连续性 → 合规（判据：hard 全过 + advisory 清单完整）。
- **分支·时间轴断裂**：定位到段 → 给出前后段主轨落点 → 建议并入/重排（判据：改后主轨连续）。
- **分支·越轴可疑**：标注相邻两镜运动方向与视线方向 → 给替代镜头或插入中性镜（判据：方向一致性恢复）。
- **分支·字幕安全区冲突**：标注冲突区域与帧号 → 建议换 placement 或改封面帧（判据：安全区复核通过）。

## SOP（每步带触发/回执/失败路径）

1. 触发（时间轴与字幕定稿）→ 跑硬项校验 → 回执：`cut_report.checks`（含 hard 标记）；失败：硬项未过即整轴退回剪辑指导，不进合成。
2. 触发（硬项通过）→ 连续性咨询项检查 → 回执：advisory 清单 + 证据帧；失败：证据缺失即标"结论不成立"，不写进报告。
3. 触发（报告出具）→ 生成返修单（段/字段/改成什么）→ 回执：`fixes[]` + 严重级；失败：返修动作不可执行即回退重写，不交付空话返修单。

## 关键指标（含基准与护栏）

| 指标 | 口径 | 基准/阈值 | 类型 | 来源 |
|---|---|---|---|---|
| 硬项漏检率 | 交付后发现的硬项问题 / 已检项 | 0 | 护栏 | 交付复盘 |
| 返修单可执行率 | 带"段+字段+改法"的条目 / 全部条目 | 100% | 护栏 | 报告校验 |
| 证据覆盖率 | 带证据（帧号/字段值）的结论 / 全部结论 | 100% | 质量 | 报告抽查 |
| 咨询项采纳率 | 被人采纳的 advisory / 全部 advisory | ≥30%（过低说明噪音大） | 质量 | 返修台账 |
| 复核耗时 | 单轴质检耗时（分钟） | ≤10（3 分钟内片长） | 成本 | 作业记录 |

## 失败模式（症状 → 检测器 → 处置）

| 症状 | 检测器 | 处置 |
|---|---|---|
| 用审美理由阻断交付 | 返修单里出现"节奏/调性/不够美" | 降级为 advisory；硬闸只留事实类 |
| 交付后才发现硬项问题 | 硬项漏检 | 补齐合法性/授权/时长/规格检查项后重跑 |
| 返修单无法执行 | 条目缺段号或改法 | 重写为"段 + 字段 + 改成什么" |
| 咨询项淹没重点 | advisory 数量异常多 | 按影响排序，只保留 Top-N 与人能执行的项 |
| 素材授权与用途不符 | 授权清单核对 | 判 hard 失败，退回补登记后重出时间轴 |

## 5. 自检清单

- [ ] 硬项（合法性/可执行性/事实合规）全部通过，否则不得进入合成
- [ ] 每条不合格都有"改哪一段、哪个字段、改成什么"
- [ ] 咨询项明确标注 `advisory`，不阻断交付
- [ ] 检查结论有证据（帧号/字段值/素材 id）
- [ ] 报告可直接进返修分诊（供剪辑制片排期）

## 6. 首尾节奏的事实验收（2026-10-15）

先读 `rhythmDirection.mode/reasons`：自然节奏可以是正确决定。选择快切时分别核对 opening/ending 的实际位置、每端短镜数与时长、正文顺序、原速台词/动作、最终落版和原请求时长带，不能以全片某处有一段短镜代替。`edit:post` 在加工前核对源字节、计划、字幕与固定配乐；加工后生成 `rhythm-direction-inspection.json`，绑定实际裁片/逐刀回执/母版对应帧与所有交付媒体。画面变化只是咨询项，不把连续运动当切镜。

发布/打包门禁重读当前媒体与节奏回执。缺回执、回执陈旧、改了成片时钟或只留下 pending 标记时不能交付；应回原草稿重新编译、字幕、后期。封面独立文件允许，另插静态片头改变时钟后须新计划。音乐瞬态与用户请求不符是事实合同失败，音乐是否悦耳、快切是否有感染力保留咨询判断。
