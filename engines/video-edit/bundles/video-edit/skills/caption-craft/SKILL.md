# 字幕与文案（caption-craft v3）

> **与生成链路的区别（重要）**：AI 剪辑链路的字幕**是剪辑的一部分**，不交给后期去"补一层字"。
> 字幕按**原始素材时间码**绑定镜头写（《剪辑脚本字幕版（音画强关联）》），输出 `video_title / video_id / total_duration /
> video_groups[group_name, group_duration, shots[original_timestamp, subtitle_text]]`；出现规则（≥2s / VMG）、
> 字数带、断句格式、结尾话术固定块见 `docs/video-edit-creation-doctrine.md` §5。
> 本地把字幕版转成交付字幕文件：`pnpm edit:subtitle -- --timeline … --caption … --out ….srt`；
> 字体/版式/平台安全区仍由后期字幕工位执行。

## 1. 定位

本技能的字数带、VMG、删修饰和改写规则适用于新写的画外文案。ASR 逐字字幕必须完整保留原话，不得套用文案规则删字、补字、概括或改写；长句使用多屏字幕承载，规则见 §8。

字幕不是"把台词抄一遍"，而是**画面信息的第二层表达**：补足画外信息、加强节奏、给出钩子与落点。
本技能产出 `caption_script`：与时间轴逐段绑定，可直接进字幕工位与封面工位。

## 1.5 风格 × 目标 × 人设（v3 新增，2026-10-11 产品所有者口径）

客户原话：**字幕文案要更像"人说的话"**；文案跟短片风格强相关（vlog / 带货 / 知识分享……），
文案服务于短片风格与短片目标，还要符合博主的人设。执行口径：

| 维度 | 取值 | 写作影响 |
|---|---|---|
| 短片风格 | `vlog` 生活流 / `promo` 带货 / `knowledge` 知识 / `story` 情感 / `food` 美食探店 | 句式节奏、口语标记、禁用词表 |
| 短片目标 | 完播 / 关注 / 转化 / 收藏 / 共情 | 每条字幕要不要给钩子、要不要给利益点 |
| 博主的人设 | 身份、受众、自称、对观众的称呼、口头禅、方言词、人设禁用词 | 人称与用词；口头禅**自然出现**，宁可少不要硬塞 |

**写作档案**（`packages/video-studio/src/edit/copy-style.ts`，唯一事实源）：

- 每条字幕必须过字数带（`ceil(时长×2.0) ≤ 字数 ≤ floor(时长×2.5)`）、行内无标点、每句独占一行；
- 口语标记（了/呢/就/都/真/还/咱/吧…）覆盖率 **≥60%**；人设词（口头禅/地域词）覆盖率 **≥20%**；
- 禁用 AI 腔与说明书腔：让我们一起 / 不妨 / 值得一试 / 尽享 / 垂涎欲滴 / 众所周知 / 非常 / 十分 /
  品尝 / 位于 / 进行 / 以及 / 并且 / 然而 / 使得 / 令人（完整词表见 copy-style.ts）；
- 无据数字/专名一律不写（机检按 facts 清单核对，命中即硬失败）。

**两个动作（同一套档案，先出简报、后验稿）**：

```bash
# ① 给"文案字幕师"岗位出写作简报（风格/目标/人设/禁用/镜头事实/原字幕）
pnpm edit:copy -- --srt <原字幕.srt> --style vlog --persona <persona.json> --facts <facts.json> --brief
# ② 对回来的文案机检（评分 + 逐条建议）；必要时做保守的规则化口语替换
pnpm edit:copy -- --srt <新字幕.srt> --style vlog --persona <persona.json> --report <报告.json> [--rewrite]
```

反例（同一画面的两种写法）：

| 说明书腔（不过） | 活人感（过） |
|---|---|
| 品尝当地的特色美食，非常值得一试 | 先来碗羊汤 热乎的 |
| 让我们一起感受美好的氛围 | 风一停 整条街都安静了 |
| 她感受到了一种幸福的氛围 | 她抬头 笑得像个孩子 |

## 2. 出现规则（硬口径）

| 情形 | 规则 |
|---|---|
| 单镜时长 ≥2.0s | 必须上字幕 |
| 单镜时长 <2.0s | 不加字幕 |
| 连续多个 <2.0s 镜头 | 合并为**虚拟拼接组（VMG）**；合并总时长 >3.9s 时，在 VMG 第一镜上写一条覆盖全组的概括字幕 |

## 3. 字数带

```
最小字数 = ceil(时长秒数 × 2.0)
最大字数 = floor(时长秒数 × 2.5)
```

- 超出上限 → 拆句或删修饰；低于下限 → 补画面事实，不补空话。
- 一条字幕 2–4 行，每行 8–14 字（竖屏可 6–11 字）；不做"一行 20 字"的糊字幕。

## 4. 文字纪律

1. **每句独占一行**（用换行分隔），行内无空格、无标点、无 Emoji。
2. 只写画面能证明的内容；不写人物内心活动、不写没出现的地点/品牌/数据。
3. 未提供售价时不写价格；不写"限时""最"等极限词。
4. 专有名词与素材事实逐字一致（品牌名、地名、产品型号）。
5. 结尾话术位：若账号配置了结尾话术（例如 AI 制作声明 + 关注引导），保留原口径，不擅自改写。

## 5. 标题与封面文案

- 标题：≤12 个中文字符（平台另有要求时按平台），有信息量或悬念，不用问号堆砌。
- 封面文案：与标题不重复，给"第二句钩子"；与主视觉（关键帧候选）匹配，避免字幕压脸。
- 封面帧优先取 `composition_best`/`emotion_peak` 关键帧，标题区避开人脸与重要信息。

## 6. 提示词正文（可直接投喂，v2）

```text

- 账号口径：{{ account_profile }}（语气/结尾话术/禁用词）
- 平台规格：{{ platform_spec }}
```

## 决策原则（含阈值与失败关闭）

1. **字幕与时长量化**：字数带 `ceil(时长×2.0) ≤ 字数 ≤ floor(时长×2.5)`；超出上限必须拆句，不得压时。
2. **出现规则硬口径**：单镜 ≥2.0s 必须上字幕；<2.0s 不上；连续短镜按 VMG 合并后 >3.9s 才给概括字幕。
3. **只写画面能证明的**：事实字段没有的地名/品牌/数据/价格一律不写；内心活动不写。
4. **格式纪律**：每句独占一行、行内无空格标点、无 Emoji、无外文（专有名词除外）。
5. **失败关闭**：段时长缺失或事实字段缺失时，该段留空并标注待补，不臆造文案。

## 打法库（场景 → 动作序列 → 判据）

- **主线·逐段写作**：读时间轴段事实 → 定信息点 → 按字数带成句 → 分行（判据：字数带命中率 100%）。
- **分支·短镜串联（VMG）**：合并连续 <2.0s 镜头 → 总时长 >3.9s 时在首镜写一条概括（判据：合并不漏内容、不超字数带）。
- **分支·信息密集型段落**：优先保留名词与动词，删修辞；必要时拆成两条并调整起止（判据：可读性抽检通过）。
- **分支·账号口径冲突**：保留账号结尾话术原文，冲突时以账号口径为准并记录（判据：话术逐字一致）。

## SOP（每步带触发/回执/失败路径）

1. 触发（时间轴锁定）→ 逐段撰写字幕 → 回执：`caption_script` + 字数带校验表；失败：字数越界或含标点即回退重写，不放行。
2. 触发（字幕初稿）→ VMG 检测与合并 → 回执：合并清单（哪些镜头合并、字幕落在首镜）；失败：合并后无概括或落错镜即重做该组。
3. 触发（字幕定稿）→ 事实口径核对（实体/价格/专有名词）+ 封面文案生成 → 回执：核对清单 + 标题/封面行；失败：出现无依据事实即删除该句并标注，不进交付。

## 关键指标（含基准与护栏）

| 指标 | 口径 | 基准/阈值 | 类型 | 来源 |
|---|---|---|---|---|
| 字数带命中率 | 落在字节带内的字幕 / 全部字幕 | 100% | 护栏 | 字数校验器 |
| 格式合规率 | 无标点/无空格/无 Emoji 的行 / 全部行 | 100% | 护栏 | 正则校验 |
| 事实准确率 | 与镜头事实一致的字幕 / 抽查字幕 | ≥98% | 质量 | 20% 人工抽检 |
| VMG 覆盖率 | 连续短镜按 VMG 处理的比例 | 100% | 护栏 | VMG 检测清单 |
| 封面安全率 | 未压脸/未压平台 UI 的封面文案 / 全部封面 | 100% | 质量 | 安全区检查 |
| 口语标记覆盖率 | 含口语标记（了/呢/就/都/真/还/咱…）的字幕 / 全部字幕 | ≥60% | 质量 | `edit:copy` 机检（copy-style.ts） |
| 人设词覆盖率 | 含口头禅/地域词的字幕 / 全部字幕 | ≥20% | 质量 | `edit:copy` 机检 |
| AI 腔命中数 | 命中 AI 腔/说明书腔词表的字幕数 | 0（硬伤为 0） | 护栏 | `edit:copy` 机检 |
| 风格机检分 | copy-style 评分（100 分制；硬伤每条 -8） | ≥90 | 质量 | `edit:copy --report` |

## 失败模式（症状 → 检测器 → 处置）

| 症状 | 检测器 | 处置 |
|---|---|---|
| 字幕读不完 | 字数超上限 | 新写文案可删修饰或拆句；ASR 逐字字幕只允许分屏，不得截断或改写原话 |
| 字幕说的事画面里没有 | 事实来源混用了剧情设计 | 只允许引用镜头事实字段；无依据的句子删除 |
| 字幕压在脸上 | 未检查安全区 | 换 placement 或改用上方安全区；封面另选关键帧 |
| 结尾话术被改写 | 模型自作主张 | 结尾话术视为账号口径，原文保留 |
| 短镜被塞满字 | VMG 规则未执行 | 合并连续短镜；>3.9s 才在首镜给一条概括 |

## 7. 自检清单

- [ ] 每条字幕字数落在字数带内；行数 ≤4
- [ ] 每句独立成行；行内无标点/空格/Emoji/外文
- [ ] 字幕内容与对应段的画面事实一致（可逐段抽查 20%）
- [ ] VMG 合并规则已执行（连续短镜合并、>3.9s 给概括字幕）
- [ ] 结尾话术位与账号口径一致
- [ ] 标题 ≤12 字且与封面文案不重复；封面文案避开人脸安全区
- [ ] 风格与目标已落到句式上；`edit:copy` 机检分 ≥90 且无硬伤
- [ ] 口语标记覆盖率 ≥60%、人设词覆盖率 ≥20%，口头禅是"自然出现"而不是硬塞
- [ ] 人设禁用词与 AI 腔词表零命中；无据数字/专名零出现

## 8. 首尾快切与字幕时钟（2026-10-15）

先取得 `edit:rhythm` 产生的 compiled 时间轴，再写字幕。`edit:subtitle` 仍输出串接时钟的 SRT；后期根据声明转场只映射一次，侧车 `.srt.rhythm.json` 保存当前轴/字幕摘要和预期最终时钟。不得自行提前扣除转场再交后期；陈旧 SRT、改轴后未重做字幕会被拦截。口播自动字幕的句级兜底明确采用均分字符时间，不能冒充实测词级；多素材逐字稿用 `sourceId` 隔离相同时间码。

ASR 长句在同一个 shot 的 `subtitle_text` 内按时间拆成多屏，每屏最多 24 字、两行、每行 12 字，所有屏拼接后必须与原话逐字一致。真实词时间标为 `word`；仅有句时间时标为 `sentence-estimated`；超长单 token 内部分屏标为 `word-estimated` 并保留 `originalWord`。不得把估计时间写成实测词边界；缺屏、重复屏、乱序屏及时间越界都应阻断交付。
